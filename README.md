## 📌 Deskripsi Aplikasi
**DodolKu** adalah aplikasi mobile berbasis Flutter yang dirancang untuk memudahkan pengguna dalam menjelajahi dan membeli berbagai varian dodol tradisional khas Indonesia. 

Aplikasi ini mengintegrasikan **Supabase** sebagai backend utama untuk manajemen autentikasi dan penyimpanan data secara aman, serta menyediakan antarmuka belanja yang intuitif.

## 🎯 Tujuan Project
* Implementasi framework Flutter dalam membangun aplikasi e-commerce.
* Simulasi alur transaksi dari pemilihan produk hingga checkout.
* Memenuhi Tugas Akhir mata kuliah Pemrograman Mobile.

## 📱 Fitur Utama
* 🔐 **Login & Register**: Sistem autentikasi pengguna via Supabase.
* 📋 **Daftar Produk**: Katalog menu dodol yang informatif.
* 🔍 **Detail Produk**: Penjelasan lengkap mengenai tiap varian produk.
* 🛒 **Keranjang Belanja**: Fitur tambah/hapus item belanja.
* ➕ **Quantity Control**: Mengatur jumlah pesanan dalam keranjang.
* 💰 **Auto Totaling**: Perhitungan otomatis total biaya belanja.
* 🧾 **Checkout**: Finalisasi pemesanan produk.
* 🚪 **Logout**: Mengamankan kembali sesi pengguna.

1. Download file `app-release.apk` (tersedia di folder release atau menu Releases).
2. Buka file di perangkat Android.
3. Klik **Install**. Jika muncul peringatan "Unknown Source", pilih **Izinkan/Allow**.
4. Aplikasi siap digunakan.
